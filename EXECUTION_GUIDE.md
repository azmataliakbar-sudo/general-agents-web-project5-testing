# Execution Guide: How to Run This Study

## Step 1: Prepare Both Platforms
- [ ] Ensure you have access to Cowork
- [ ] Ensure you have access to ChatGPT Work
- [ ] Have them open in separate windows/tabs

## Step 2: Run the Assignment on Cowork
1. Copy the exact prompt from `assignment.md`
2. Paste it into Cowork
3. Watch the execution from start to finish
4. Document observations in `observations/cowork-run.md`:
   - Progress signals (what did you see?)
   - Tools it chose and why
   - Errors or recoveries
   - How long it took
   - Final result quality and structure
   - Screenshot key moments if possible

## Step 3: Run the Assignment on ChatGPT Work
1. Copy the exact same prompt
2. Paste it into ChatGPT Work
3. Watch the execution from start to finish
4. Document observations in `observations/chatgpt-work-run.md` using the same structure

## Step 4: Map to Framework
1. Open `observations/framework.md`
2. For each of the six concepts (Heartbeat, Reach, Loop, Spine, Gate, Body):
   - Describe what you observed in Cowork
   - Describe what you observed in ChatGPT Work
   - Note the key difference (ignore UI/cosmetic differences)
3. Fill in the comparison matrix at the end

## Step 5: Write the One-Page Comparison
1. Open `comparison.md`
2. Fill in each section with your observations
3. For each part, identify at least one concrete implementation difference
4. Write the summary showing both platforms have the same six-part shape
5. Conclude with implications

## Step 6: Review for Completeness
✓ Same assignment given to both platforms  
✓ At least one implementation difference identified in each of the six parts  
✓ Comparison shows the same six-part shape underneath both  
✓ One-page (or close to it)

---

## Tips

**Ignore Superficial Differences**:
- Different button colors, fonts, layouts
- Focus on: structural choices, capabilities, constraints

**Look for Asymmetries**:
- Can Cowork do something ChatGPT Work can't?
- Does one show progress more clearly?
- Do they handle errors differently?

**Be Specific**:
- Don't say "both use web search"
- Say "Cowork shows search queries in real-time; ChatGPT Work only shows final search results"

**Time Yourself**:
- How long did each take?
- Why? (Did one do more iterations? Parallel execution?)
