# The Assignment: Simple Research Agent

## Task (Give this EXACT prompt to both platforms)

> Build a simple agent that:
> 1. Takes a user question: "What are the top 3 recent advances in AI?"
> 2. Breaks the question into 2-3 sub-steps needed to answer it
> 3. Executes those steps
> 4. Collects and synthesizes the results
> 5. Returns a final answer
>
> You can use: web search, document retrieval, or any available tools.
> Constraint: Use only built-in tools (no custom APIs).
> Time limit: Execute within 30 seconds.

## Why This Assignment?

This is **low-stakes** (no real consequences) but reveals:
- **Heartbeat**: Progress signals while thinking
- **Reach**: Which tools/resources each platform can access
- **Loop**: How they refine or re-query if results are incomplete
- **Spine**: The core structure they use to organize multi-step work
- **Gate**: How they authenticate/authorize tool access
- **Body**: Actual implementation details (prompting, error handling, etc.)

## What to Observe

For each platform, document:
- ✓ How the agent breaks down the task
- ✓ Which tools it chooses and why
- ✓ How it signals progress to the user
- ✓ How it handles errors or missing data
- ✓ Final structure of the response
- ✓ How long it takes and what that tells you

Keep notes brief and focused on the six concepts.
